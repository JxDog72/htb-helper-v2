    Export to your host
    
            
    Packs logs, screenshots, notes, report, and files_given as student_machine_….zip next to machines/. App files in machine_json/ stay on the box and are not in the archive.
    
            
            
    
            
    Pwnbox → host (SCP)
    
            
    From View instance details fill hostname and username. Path is the archive on Pwnbox (filled after Create ZIP / 7z). Run the command on your Windows PC, then enter the instance password. No space after the colon.
    
            
            
            
            
    scp USER@HOST:/path/file.zip %USERPROFILE%\Downloads\
    
            
    Encrypt (7z, stronger than zip -e)
    
            
    Parrot does not always ship 7z. Install once: sudo apt install p7zip-full. Header encryption (-mhe=on) hides filenames too.
    
            
            
            
    
            
    sudo apt install p7zip-full
7z a -t7z -mhe=on -p myarchive.7z student_machine/
    
            
    Own VM (not Pwnbox)
    
            
    Skip scp: enable a VirtualBox/VMware shared folder, or drag the zip/7z onto your host desktop.

    Help
    

          
    First install (Parrot / Kali)
    
          
    git clone https://github.com/JxDog72/htb-helper-v2.git
cd htb-helper-v2
chmod +x install.sh htb
./install.sh
./htb
    

          
    Start commands (Linux)
    
          
    cd htb-helper-v2
chmod +x htb install.sh   # if ./htb says Permission denied — do NOT sudo
./htb                     # GUI + logged work shell (use this for labs)
bash ./htb                # same, if execute bit is still off
./htb --gui-only          # browser only; this terminal stays a normal shell
./htb --cli               # original numbered menu (no GUI)
./htb --check             # environment check, then exit
./htb --port 9000         # if 8765 is taken (also auto-tries 8766–8784)
python3 htb_app_lib/htb_app.py
python3 htb_app_lib/htb_helper.py
    
          
    Default GUI port is 8765. Override with ./htb --port 9000. Then open http://127.0.0.1:9000/.
    
          
    GUI: http://127.0.0.1:8765/. After lab identity is set, ./htb turns this terminal into the logged session.
    

          
    Start commands (Windows)
    
          
    cd htb-helper-v2
.\install.ps1
.\htb.cmd
.\htb.cmd --gui-only
.\htb.cmd --cli
.\htb.cmd --check
.\htb.cmd --port 9000
python htb_app_lib\htb_app.py
    

          
    Update to the latest
    
          
    cd htb-helper-v2
git stash
git pull
# then restart: exit, Ctrl+C, ./htb
    
          
    If git says local files would be overwritten, run git stash first. Your machines/ notes and config.json are not in git.
    

          
    Switch lab / no identity prompt
    
          
    On start you should see Choose a machine: pick an existing lab or create a new one. Later use Switch lab in the header. The helper no longer skips that screen just because a previous lab was saved.
    

          
    How do I stop?
    
          
      
            
    1. In the logged terminal type exit (ends session.log).
      2. 
            
    2. Then Ctrl+C in that same terminal to stop the GUI.
      3. 
          
    
          
    Ctrl+C during a scan (ping, nmap, tracert) should stop that command, not the helper. If the GUI dies too, just start ./htb again.
    

          
    Starting again the next day?
    
          
    Run ./htb again. It does not overwrite the old log. You get session.log, then session2.log, session3.log, and so on.
    

          
    Where is my work?
    
          
    machines/<student>_<machine>/ holds logs/, screenshots/, notes/ (notes.md + evidence.md), report/, files_given/, and machine_json/ (app-only).
    

          
    Export ZIP / 7z and copy off Pwnbox
    
          
    Status → Create ZIP, or set a password and Create encrypted 7z (sudo apt install p7zip-full once). The file is next to machines/, not inside the lab folder.
    
          
    On your Windows PC, use hostname + username from View instance details. Path is filled after you create the archive. No space after the colon. Command Prompt uses %USERPROFILE%\Downloads\ (not $HOME).
    
          
    scp USER@htb-xxxxx.htb-cloud.com:/full/path/to/file.zip %USERPROFILE%\Downloads\
    
          
    PowerShell: same line but $env:USERPROFILE\Downloads\. Enter the instance password when asked. Own VM: shared folder or drag-and-drop.
    

          
    Tools IP / port stuck?
    
          
    Lab identity is only the default. On the Tools form, change Target IP and Port for that run (another host, a new port, etc.). The Command box is the line that actually runs — edit it, or use Extra arguments and Reset command. Stop tool kills the current helper-launched scan (nmap, ping, gobuster, …) without closing the GUI.
    

          
    Nmap files
    
          
    Each helper nmap run keeps a streamed .txt and nmap’s own .nmap. No xml/gnmap.
    

          
    E-ID
    
          
    E-001 is just the next evidence number so you can cite it in the report (like a footnote ID).
    

          
    Report tab
    
          
    Use Display: 1 Write, 2 View, 3 Both. Auto-saves to report/report.md. Insert findings adds only evidence IDs (E-001, …) that are not already in the draft. Reset template replaces the whole file. Paste images with Ctrl+V — report/media/ is created only when you paste.
    

          
    Validation [WARN] user_flag
    
          
    That is not asking you to type user_flag in notes. It only means you have not recorded a user-flag screenshot yet (Status → or Evidence / screenshot). WARN here is a reminder, not a failure. Same for root_admin_flag and other screenshot milestones.
    

          
    Pause / resume session logging
    
          
    Header → Session ▾ → Pause or Resume. The terminal still works while paused; commands are not written to session.log until you resume. Requires ./htb (not --gui-only).
    

          
    Notes: Split / Write / Nice view
    
          
    Split is raw markdown on the left and preview on the right. Write is the editor only. Nice view is the formatted preview (read-only) after you finish writing. Switch back to Write to edit again.
    

          
    Logs
    
          
    Live view (checked by default) tails the session. Uncheck it on a slow Pwnbox so the GUI does not keep fetching the log. Use Refresh when you want a snapshot. Each ./htb start gets session.log, then session2.log, and so on.
